## Summary
Snake game written in C++ and raylib
- have start menu with clickable and hoverable button
- two difficulty levels (Easy and Hard)
- highscore is saved in highscore.txt

# How to play
- use arrow key to move the snake around, avoid hitting the wall and hitting yourself

## Building (Windows, MSYS2 + VS Code)
- Install raylib in the **MSYS2 UCRT64** terminal:
- pacman -S mingw-w64-ucrt-x86_64-rayl
- Run `snake.exe`.
